# 行情跳动

> 当前上线方案为个人试运行：不加载演示报价，使用独立的 `hqt-trial-data-v1` 保存人工询价；真实采集线索可核对入库。报价仅保存在当前浏览器，员工登录、跨设备共享和账号管理前端暂未启用。Supabase 权限后端已单独部署，后续完成管理员密码及前端接入再切换共享模式。

一个简洁的禽畜采购比价工作台。首批支持猪、鸡、鸭、鹅、羊，可继续添加牛、兔等品类及具体规格。目标仓库：https://github.com/taojin1174-cyber/JYE 。

## 运行

要求 Node.js 22 或更新版本，不需要安装第三方依赖。

```sh
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。检查与构建：

```sh
npm test
npm run build
```

`dist/` 是可部署的静态网站；所有资源使用相对路径，支持 GitHub Pages 的 `/JYE/` 子路径。

另可运行 `npm run preview:offline`，生成 `artifacts/行情跳动-离线体验.html`，直接用浏览器打开。它内嵌代码和公开线索快照，始终使用本机演示模式，不含数据库配置；适合先体验页面和流程，不能代替线上共享库。

## 已实现

- **行情总览**：各品类的明确代表规格、全部产品规格参考均价、最低价、区间、有效样本数、覆盖省份、7 日趋势。
- **采购比价**：品类、产品规格（含鲜冻）、省份、周期、价格口径、来源筛选；供应商搜索；价格或时间排序；起订量、已知运费和来源详情。
- **人工报价**：录入及管理员编辑；元/kg、元/斤、元/吨统一换算；报价日期、有效期、供应商、地区、备注。
- **报价审核**：确认、忽略、退回待审；查看已入库与过期历史记录。编辑人员提交的报价必须经管理员审核。
- **产品库**：添加新物种、部位和规格。
- **数据导出**：按当前筛选导出 UTF-8 CSV；完整 JSON 备份。JSON 暂无网页恢复入口，后续可加校验后导入。
- **团队接入代码**：Supabase 邮箱密码登录，管理员 / 编辑 / 只读角色；数据库 RLS 权限；报价审核与修改审计表；管理员调整已授权成员角色。
- **来源中心**：收在“数据设置 → 来源中心”中，统一经过设置入口密码验证。展示真实公开线索与候选来源目录；肉交所公开供货列表、禽网行情目录、全国畜牧总站监测目录已做适配。采集线索与报价库独立，补全规格、供应商及价格口径后才能转入。市场行情、官方监测不能转成供应商供货价。
- **定时采集器**：公开网页线索每天北京时间约 08:10 / 14:10 / 20:10 更新；另支持 JSON / CSV 授权接口、字段映射、日期与单位校验、重复采集去重、待确认入库，每天约 08:20 / 14:20 / 20:20 执行。GitHub Actions 调度可能延迟。

## 当前边界

默认是**本机演示模式**。均价和报价库的演示行情完全为虚构数据，不用于采购决策；录入仅存在当前浏览器 localStorage，清理网站数据会丢失。来源中心展示独立的真实公开采集快照；采集线索尚未被认证为可采购报价。没有连接共享数据库或线上账号。演示报价不会自动迁移到共享库。

已包含团队数据库和前端接入代码，但仍需真实项目中执行 SQL 并验证三种角色后，才算完成团队环境上线。原生浏览器 JavaScript 无构建依赖；不引入无用途的 UI 框架。

公开线索已启用三个网页适配器；JSON / CSV 授权接口尚未配置。搜索引擎摘要、网页标价、零售价格不能直接当作可采购的供货价；必须核对日期、规格、产地和价格口径。公众号、其他网页、登录后或付费来源需要逐一适配，尚未实现通用网页爬虫或 AI 全网搜索。

## 数据设置入口密码

“数据设置”中的基础设置和来源中心共用入口密码。直接访问旧的 `#sources` 或新的 `#settings/sources` 地址同样先验证密码。解锁状态仅保留在当前标签页的 sessionStorage 中，刷新后继续有效，关闭标签页后失效；也可点击“锁定”立即重新锁住。

仓库只保存随机盐与 PBKDF2-SHA-256 派生校验值，迭代 600000 次，不保存明文密码。修改入口密码时运行：

```sh
node scripts/set-settings-password.mjs
```

在隐藏输入提示下输入新密码并回车，然后构建发布。不要把密码写到命令参数、配置说明或提交记录里。修改密码后原会话失效。

这是静态测试版的页面入口锁，不能作为服务器访问控制：静态代码与公开采集快照仍可直接读取，浏览器校验也可被绕过。正式多人数据的读取、编辑、审核权限由 Supabase 登录和数据库 RLS 控制。

## 均价口径

1. 一个产品定义 = 品类 + 产品 / 部位 + 鲜冻 / 活体状态 + 等级和重量规格。例如“白羽鸡 / 鲜品 / 白条整鸡 · 1–1.5 kg/只”。
2. 出厂含税不含运、到货含税、出厂未税不含运分别统计。所有供货报价统一换算为人民币元/kg。无法按重量比较的计件产品需补充重量换算后再录入。
3. 只取参考周期内、已审核、报价日不晚于统计日、有效期覆盖统计日的报价。同供应商名称（忽略首尾空格与大小写）、同省份、同规格、同口径只保留最新一笔。
4. 按有效供应商样本等权计算算术平均，另显示中位价、最低价、最高价。供应商名称应统一填写，避免别名造成重复计权；正式阶段可建设独立供应商主档。
5. 不足 5 条或覆盖不足 3 省标记“样本较少”。全国地区指采样范围，不等同官方或具有统计代表性的全国均价；各省样本密度仍可能不均。
6. 不混算不同规格的“鸡均价”“猪均价”。总览卡片展示每个品类的第一个产品规格；所有规格可在下方表格查看。后续可增加可配置的常采规格。
7. 7 日走势按历史当天有效样本回算；补录或调整审核状态可能改变历史结果，不是冻结的日报。若要固定每日参考值，后续增加每日快照表。
8. 参考含运价 = 供货价 + 已填写的每公斤运费。运费未知显示“待询”，不按 0 算；未税报价的含运参考价仍未含税。不同目的地的运费需分开询价。

## 部署到指定 GitHub 仓库

代码推送到 `taojin1174-cyber/JYE` 的 `main` 分支后：

1. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
2. 在 **Actions** 运行 `Deploy GitHub Pages`。工作流先执行测试，再构建和部署。
3. 未设自定义域名时，默认地址为 `https://taojin1174-cyber.github.io/JYE/`。本项目已设置自定义域名 `bbroot01.bbroot.com`，启用后默认地址可能重定向到该域名；需要 DNS 生效才可正常访问。只有成功的工作流和实际 HTTP 验证才能证明已上线。

如果 GitHub 账号套餐或组织策略不允许当前仓库启用 Pages，请按 GitHub 显示的要求处理；代码本身也可部署到其他静态托管服务。

根目录 `CNAME` 已填写 `bbroot01.bbroot.com`，构建时复制到发布目录。在管理 `bbroot.com` 的 DNS 服务商添加：类型 **CNAME**，主机记录 **bbroot01**，目标 **taojin1174-cyber.github.io**，TTL 默认；目标不能带协议或 `/JYE/`。同名旧 A / AAAA / CNAME 记录不能与新 CNAME 冲突。再在 GitHub Pages 设置相同的 Custom domain，等 HTTPS 证书生效后启用 Enforce HTTPS。

参考：[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) · [自定义域名](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)

## 接入共享数据库与同事权限

1. 创建你自己的 Supabase 项目，在 SQL Editor 中执行 `supabase/schema.sql` **一次**。脚本建立产品、报价、采集线索、成员、审计表，打开全部 RLS；只初始化产品定义，不导入演示报价。
2. 在 Authentication 中创建 / 邀请管理员账号并设置密码。在 SQL Editor 执行脚本末尾示例，将该账号加入 `members`，角色为 `admin`。建议关闭公开用户注册；未入 `members` 的账号没有业务数据访问权。
3. 修改根目录 `config.js`，填写项目 URL 和 **publishable key 或 anon 公钥**。此文件会公开给浏览器，这是预期行为。**严禁填写 service_role / secret key**。
4. 把正式网站地址加入 Supabase Authentication 的 Site URL / Redirect URLs。若通过邀请邮件设置密码，先在 Supabase 端完成账号密码设置；本项目只提供邮箱密码登录，暂不提供邀请回调及忘记密码页面。
5. 重新发布网站。正确配置后不展示演示行情，必须登录才访问共享库。首次报价库为空。给采集工作流设置数据库 Secrets 后，运行 `Discover public price leads`，真实线索会写入共享的 `collection_items`，不从浏览器演示库搬入。
6. 同事账号由管理员在 Supabase Authentication 创建 / 邀请，然后 SQL 加入 `members`，填入 email、display_name、role。已有成员角色可在网站“管理成员”中修改。成员停用在 Supabase 中操作，本版暂无网页禁用入口。

权限由数据库验证，并非浏览器隐藏按钮：

| 角色 | 查看 | 新增报价 | 审核 / 修改报价 | 添加规格 / 管理成员 |
|---|---|---|---|---|
| 管理员 admin | 全部 | 可直接入库或待审 | 可以 | 可以 |
| 编辑 editor | 已入库和自己提交的报价 | 仅待确认 | 不可以 | 不可以 |
| 只读 viewer | 仅已入库 | 不可以 | 不可以 | 不可以 |

匿名用户不可读写业务表。采集服务私钥只放服务器 / GitHub Secrets。数据库 `quote_audit` 保存每次报价新增或修改的前后记录及操作者，仅管理员可读；本版尚未提供审计记录页面。

正式投入多人使用前验收：未登录无法获取数据；viewer 直接发写入请求失败；editor 提交 approved 失败、pending 成功、修改失败；admin 能审核且审计有记录；移除成员后刷新无法读取；确认供应商隐私信息符合内部访问范围。还未在真实 Supabase 项目执行这些在线检查。

参考：[Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security)

## 配置真实采价

### 已接入的公开列表

```sh
npm run discover
```

此命令只读访问 `collector/web-sources.json` 中启用的公开列表，生成 `data/discovery.json`。快照仅含原文短标题、URL、明确标价、原文地区、发布时间和必要口径说明，不含商户联系方式、全文或登录内容。来源目录中的其他候选站点标注“待核验”或“待适配”，不能据目录推断已经采集。

GitHub 工作流 `Discover public price leads` 会定时生成快照、提交到仓库并部署。`GITHUB_TOKEN` 提交不会触发另一个 push 工作流，因此该工作流明确执行自己的发布步骤。来源临时失败时保留该来源旧线索，运行标记失败；日期始终保留原文时间。需要启用 Actions 的仓库写权限以及 Pages。

配置数据库 Secrets 后，同一采集任务把线索同步到 Supabase。线索转报价与状态更改由数据库触发器在同一事务完成；唯一键防止不同同事对同一线索重复生成报价。仅供货线索可以转换，市场 / 宏观类型不能转换。

肉交所列表中的“货量”是现货发布量，不能推断为起订量；“仓库地区”不能推断为商品产地。供货商身份、产品鲜冻及具体规格、含税及含运状态均需人工核实，表单不会自动选取默认规格和税运口径。原文有明显异常标价也原样呈现，待询价核实，不自动修正成看似合理的数。

### 鸡鸭鹅行情价（禽网，2026-11-10 接入）

四个抓取目标，每次取当日最新一篇，输出带结构化价格字段的记录：

| 来源 ID | 内容 | 原文单位 | 折算方式 |
| --- | --- | --- | --- |
| `cnfowl_rouji` | 全国肉鸡（817、白羽、青脚麻、黄花公），鸡苗与毛鸡，按省区 | 元/羽、元/斤 | 苗不折算；毛鸡 ×2 |
| `cnfowl_rouya` | 全国肉鸭（樱桃谷、麻鸭、骡鸭、白番），鸭苗与毛鸭，分北方冻品区 / 中部半活禽区 / 南部活禽区 | 元/羽、元/斤 | 同上 |
| `cnfowl_baotiao` | 全国主要批发市场白条鸡当日价，逐市场 | 元/公斤 | 直取 |
| `cnfowl_shixing` | 石兴鹅 / 鸡 / 鸽日报，广东主产区鹅苗与毛鹅 | 元/只、元/斤 | 苗不折算；毛鹅 ×2 |

每条记录在原有线索字段之外增加 `market`：`{breed,region,spec,unit,stage,price_low,price_high,price_mid,unit_norm,price_norm_mid,price_norm_low,price_norm_high}`。

口径纪律：

- 只做 元/斤 → 元/公斤（×2）与 元/吨 → 元/公斤（÷1000）。元/羽、元/只 属苗价，保留原单位，`price_norm_*` 为 `null`，绝不与毛禽混算。
- `stage` 区分苗 / 毛禽 / 白条分割 / 整只。总览按 stage 分组各取自己的中位价，不合并成“鸡均价”。
- “胴体”“活禽”“旱鸭”是规格而非产区，解析时沿用上一行省区，避免把规格写成地区。
- 行情价只进入总览的“外部行情参考”，不参与供货均价；`market` 类型线索不提供“核实入库”。
- 页面改版时该来源标记失败并保留旧线索，其余来源照常更新；解析逻辑有 `tests/cnfowl-price.test.mjs` 覆盖，改结构前先跑 `npm test`。

#### 网络前提：禽网只能在境内抓（2026-11-10 实测）

GitHub Actions 运行在境外机房，实测抓 `cnfowl.com` 与 `nahs.org.cn` 一律 `fetch failed`，肉交所正常。因此**云端定时采集只能拿到肉交所的线索，禽网鸡鸭鹅行情必须从境内网络发起**。

- 云端定时（`.github/workflows/discover.yml`，北京时间 08:10 / 14:10 / 20:10）继续跑，能拿到的源照常更新；失败源沿用上次快照，页面不会空白。
- 单个源失败只写运行摘要与 `::warning::`，不再把整次运行标红，也不阻断发布。
- 需要禽网当日报价时，在本机（境内网络）双击 `scripts/local-discover.cmd`：采完自动提交并推送 `data/discovery.json`，云端随即重新构建发布。可自行加 Windows 计划任务定时执行。
- 抓取失败会带上 Node 的 cause 码（如 `ENOTFOUND`、`ECONNRESET`、`HTTP 403`），便于判断是 DNS、连接被拦还是站点改版；网络类失败自动重试两次。

### JSON / CSV 授权接口

`collector/sources.example.json` 只演示映射格式，地址不可作为行情来源使用。把真实授权接口配置写入 `collector/sources.json`，确认 `enabled: true`。

- `format`：`json` 或 `csv`。JSON 用 `recordsPath` 指定记录数组；CSV 首行为表头，支持带引号的逗号和换行。
- `mapping`：内部字段到来源字段名 / 点路径的映射。可映射 product_id、supplier、province、city、price、unit、quoted_on、valid_until、source_url、min_order、freight、notes 等。
- `defaults`：仅对来源可明确保证的固定字段填默认值，例如 product_id、basis、unit。产品 id 必须与数据库一致；单位只认 `kg / jin / ton`。
- 日期统一为 `YYYY-MM-DD`；来源必须提供真实报价日，不允许自动把抓取日当成报价日。无有效期时仅视为报价当日有效。原始日期格式和单位名称不同的来源，应先增加专用转换适配器。
- 来源密钥放 GitHub Secrets。`headersEnv` 可以引用 JSON 请求头环境变量名称，同时须在 collect 工作流的 env 中显式传入对应 Secret。配置文件不要出现 token、账号或带密钥 URL。
- 在仓库 Actions Secrets 中设置 `SUPABASE_URL` 与 `SUPABASE_SERVICE_ROLE_KEY`，只用于定时采集工作流，**不能放前端 config.js**。
- 先手动运行 `Collect pending quotes` 查看结果，再核对网站待确认列表。相同来源、供应商、产品、省份、口径、报价日及价格的记录会去重；已忽略报价不会因重复采集重新出现。价格变动会形成新待审记录。
- 定时任务无来源时正常退出；有配置却失败或出现无效记录时工作流失败，已成功处理的数据保留。日志不输出原始报价、凭证或响应正文。

采集配置中需按实际来源决定是否能够使用、调用频率及字段准确性。当前没有预设付费服务，也没有自动订购接口。

## 后续建议，尚未实现

优先按真实采购习惯完善产品与供应商主档，再增加以下功能：

1. **采购目的地与到货总成本**：统一计算运费、税费、损耗、账期成本，找真正划算的供应商。
2. **每日行情快照**：保存每日同口径均价；查看周 / 月变化，避免历史补录改变当时的判断依据。
3. **价格异常与采样补齐**：提示明显偏离中位数的报价，不自动删去；显示哪些省份和规格缺样本。
